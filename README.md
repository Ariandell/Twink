# Twink — Android + Web

Застосунок для вивчення німецьких слів та ідіом: словник, папки, картки з перевертанням, інтервальне повторення, іспит, профіль, статистика й імпорт/експорт Excel.

У гілці **experimental** Android **0.3.1** використовує власні Flutter-віджети. WebView, локальний HTTP-сервер і завантаження HTML/JavaScript в Android вилучені. Версія 0.3.1 повертає скло з розмиттям фону, відблисками та рухомою капсулою навігації, компактну сітку папок і пропущені елементи початкового інтерфейсу. Вебверсія залишається React-оболонкою з оригінальним інтерфейсом. Стабільна гілка `main` розвивається окремо. Звіт про відновлення й межі перевірки: [docs/native-parity-audit.md](docs/native-parity-audit.md).

## Запустити вебверсію

Потрібен Node.js 24.

```sh
cd web
npm ci
npm run dev
```

Відкрийте адресу, яку покаже сервер, з параметром `?demo=1`. Демо містить локальні приклади та не змінює дані у Firebase. Для виходу з демо використовуйте `?demo=0`.

```sh
npm test
npm run build
npm exec vite preview -- --host 127.0.0.1 --port 4173
```

Готова вебзбірка — у `web/dist`. Для статичного хостингу завантажуйте її вміст у корінь сайту. Для мікрофона та PWA у публічному розгортанні потрібен HTTPS.

## Зібрати Android

Перевірено з Flutter 3.47.2 / Dart 3.13.2. Android збирається незалежно від вебверсії: іконки та шрифти вже є в репозиторії.

```sh
cd android
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

APK з'явиться у `android/build/app/outputs/flutter-apk/app-release.apk`. Для запуску демо в Android:

```sh
flutter run --dart-define=TWINK_DEMO=true
```

Для оцінки плавності запускайте `flutter run --profile` на фізичному Android-пристрої або встановлюйте release-APK. Поточний release використовує тестовий підпис для локального встановлення; публікація в Google Play потребує власного підпису.

Після переходу з WebView потрібно повторно увійти в обліковий запис. Словник, папки, прогрес і статистика беруться з того самого Firebase. Локальна сесія входу, кеш голосу й тема WebView не переносяться. Дані синхронізуються під час відкриття, після запису та кожні 15 секунд; без мережі збереження показує помилку. Повноцінної офлайн-черги записів немає.

## Озвучення та конфігурація

Приватних ключів ElevenLabs у репозиторії немає. Без ключа клієнт використовує системний голос, якщо він доступний на пристрої.

Для власного ключа у вебі скопіюйте `web/.env.example` у `web/.env.local` та заповніть `VITE_ELEVENLABS_API_KEY`. Для Android:

```sh
flutter run --dart-define=ELEVENLABS_API_KEY=YOUR_KEY
```

Значення Vite та `dart-define` включаються у клієнтську збірку. Для власної розробки використовуйте окремий обмежений ключ; для спільного публічного сервісу з приватним ключем потрібна серверна інтеграція.

Початкова клієнтська конфігурація Firebase збережена у `web/public/classic/firebase-config.js`. Самих даних користувачів та серверних облікових даних у коді немає. Доступ до живих даних визначається наявними Firebase Rules. Для окремого розгортання налаштуйте власний Firebase-проєкт. Для внесення змін до інтерфейсу використовуйте деморежим.

## Структура

- `web/src` — React-оболонка, аудіоклієнт та інтеграція оригінальних модулів.
- `web/public/classic` — початкові екрани, стилі та скрипти; приватні API-ключі вилучені.
- `web/public/classic/compat-layout.css` — виправлення мобільного компонування, довгого тексту й світлої теми.
- `web/scripts` — підготовка локальних бібліотек та PWA; `native-icons.mjs` відтворює SVG-іконки для Flutter з оригіналу.
- `android/lib/native` — власні екрани Flutter, нативне перевертання картки й окремий шар малювання шлейфу.
- `android/lib/repository.dart` — Firebase Auth / Realtime Database через REST; `domain.dart` — правила навчання та Excel.
- `android/lib/speech.dart`, `audio_api.dart`, `spreadsheet.dart` — ElevenLabs із кешем та системним голосом, обробка таблиць.
- `contracts` — контракти правил навчання та контрольні суми початкових ресурсів після вилучення ключів.
- `templates` — приклади Excel для імпорту.

Згенеровані веббібліотеки не зберігаються у Git. Вихідні початкові стилі й розмітка збережені; вилучення ключів враховане в контрольних сумах. Android не пакує `classic`-ресурси. Шрифт Outfit із веборигіналу та Roboto для кирилиці поставляються разом із застосунком і ліцензіями.

## Перевірки

Вебтести охоплюють правила навчання, Excel, аудіо та незмінність початкових ресурсів. 92 Flutter-тести перевіряють контракти правил, Firebase REST, Excel, озвучення й дії з нативними екранами: пошук/редагування, перевертання/оцінювання/скасування, іспит, фільтри, створення папок слів та ідіом, видалення/відновлення поточної картки, довгий текст і теми. Перевіряються розміри 320×568, 390×844, 568×320 та 1024×768, реальне розмиття пікселів під склом і відсутність безперервної анімації у спокої. Для збереження знімків екранів у сусідню папку `native-qa`:

```sh
flutter test --dart-define=CAPTURE_NATIVE=true test/widget_test.dart
```

Таймер оновлює лише лічильник; шлейф перемальовується окремо та зупиняється у спокої. Excel обробляється в окремому isolate. Візуальна перевірка зроблена за рендерами Flutter та вебеталоном. **Вимірів FPS на фізичному телефоні поки немає**; остаточну відповідність вигляду й поведінки, системне озвучення, мікрофон і файловий діалог треба перевірити на Android. Вибір «Браузерная»/ResponsiveVoice у нативній збірці використовує Android TTS; ElevenLabs зберігає вибрані ідентифікатори голосів.

## Запропонувати зміни

Для експериментальної версії робіть **Fork → окрема гілка → Pull Request** до `experimental`. Проблеми та пропозиції можна додавати в Issues. Інструкція: [CONTRIBUTING.md](CONTRIBUTING.md).


### Оптимізація навігації на основі 0.3.1

Збірка 0.3.1+10 зберігає вже відкриті вкладки та їхнє прокручування, зупиняє анімації прихованих вкладок і не перебудовує тему застосунку під час перемикання. Кеш екранів оновлюється після змін даних, налаштувань або розмірів екрана. Сортування папок використовує попередньо обчислені ідентифікатори. Скло та початкове оформлення збережені. Повторне натискання активної вкладки не перезапускає екран. Плавність потрібно додатково перевірити на фізичному телефоні.


### Наближення до оригінального дизайну — 0.3.2+11

На основі 0.3.1 повернуто Outfit (з локальним Roboto для кирилиці). Обертання картки триває 600 мс із cubic-bezier(.4,.2,.2,1), перспективою -1/1500 та правильно орієнтованою зворотною стороною. Перемикання сторін залишається прив’язаним до кута 90°, щоб уникнути порожнього кадру; фіксовану вебову затримку 300 мс не відтворено. Зменшення руху вимикає перегортання.

Налаштування сесії відкриваються скляною накладкою поверх картки з появою 500 мс; селектори мають висоту 44 px. Розгортання секцій використовує тривалості 800/600/700 мс для розміру, прозорості й руху, зсув 15 px та масштаб .97→1. Фільтр blur(5px) самих елементів секції не дублюється. Панель навігації зменшено до 56 px, піктограми — до 18 px. У словнику збільшено відступи, приглушено редагування та повернуто червоний акцент видалення. Підсилено світіння графіка профілю.

Покадрові знімки перевіряють перегортання, а тест — сталість компонування й переривання повторним натисканням. Це наближення до еталона, а не підтвердження піксельної ідентичності всіх екранів; лишаються парне порівняння іспиту, редакторів та загальних налаштувань і перевірка на фізичному Android. Оптимізацію навігації з попередньої збірки збережено.


### Сталий розмір карток — 0.3.3+12

Картка навчання має висоту 320 px, на вузькому (до 360 px) або низькому екрані — 280 px. Розмір не залежить від слова, обраних полів чи сторони картки. Вміст підбирає найбільший масштаб, що поміщається, зі зменшенням максимум приблизно на 10%; базовий приклад 14.4 px залишається щонайменше 13 px. Надмірний текст прокручується всередині картки з видимим повзунком. Кнопка редагування й рамка зберігають розмір. Два додаткові тести перевіряють довгі приклади й переклад, прокручування, перевертання та перехід до іншого слова без зміщення оцінок відносно картки на 320×568 і 390×844.


### Повернення картки після оцінювання — 0.3.4+13

Після оцінки на стороні перекладу та сама картка анімовано повертається на німецьку сторону з наступним словом. Контролер обертання зберігається при зміні слова; попередній переклад залишається на видимій зворотній стороні до її відходу за край. Вміст і прокручування нового слова отримують окремий стан. Регресійний тест перевіряє проміжний поворот, попередній переклад, кінцеве наступне слово та незмінний розмір.


### Перша сторона карток — 0.3.5+14

У налаштуваннях сесії в розділі оформлення додано вибір «Первая сторона»: «Немецкое слово» (типово) або «Перевод». Значення firstSide зберігається разом з налаштуваннями study у Firebase. Вибір застосовується після збереження до поточної картки, початку/відновлення сесії, наступного слова, скасування оцінки й редагування; закриття без збереження скасовує зміни. Працює для слів та ідіом. Озвучення враховує видиму сторону та відповідні перемикачі. Іспит зберігає власний порядок запитання й відповіді. Перехід після оцінювання працює симетрично в обох напрямках, із попередньою видимою стороною до краю обертання.


### Швидке відкриття наступної картки — 0.3.6+15

Наступне слово показується одразу після оцінки, до відповіді Firebase; його можна перегортати. До підтвердження запису наступну оцінку й вихід заблоковано. Позиція сесії та історія фіксуються після успішного запису; при помилці повертаються попередня картка й сторона з повідомленням повторити спробу. Це один незавершений запис, а не черга для офлайн-роботи.

Збереження прогресу більше не завантажує весь словник: локально оновлюються лише підтверджені поля. Старі відповіді опитування не стирають нові підтверджені оцінки. Збереження позиції сесії не перебудовує тему. Список слів кешується в сесії та оновлюється при зміні даних; відновлення за ID використовує індекс. Картка має дві окремі межі перемальовування замість дубльованої прихованої розмітки; під час анімації змінюються тільки поворот і видима сторона.

Тести перевіряють затриману/невдалу відповідь, миттєвий показ наступного слова, можливість його перевернути, блокування повторної оцінки, відкат, відсутність зайвого GET та захист від застарілої відповіді. Перевірки не вимірюють FPS на фізичному телефоні.


### Стабільний рух під час підтвердження оцінки — 0.3.7+16

Під час обертання повідомлення сховища про зміни накопичуються, а оновлення історії/позиції сесії після ACK і запуск озвучення відкладаються до завершення анімації. Нова мережева оцінка надсилається одразу; затримується тільки робота інтерфейсу після відповіді. Повна відповідь опитування словника теж обробляється після руху, а нове опитування під час нього пропускається. Блокування знімається при завершенні контролера, виході з екрана, відкритті діалогів або переході застосунку у фон.

Новий регресійний тест імітує ACK на 100-й мілісекунді переходу «переклад → оцінка → наступне слово»: до кінця обертання сторони не перебудовуються, фонові екрани не отримують повідомлення; після завершення отримують одне узгоджене оновлення. Тест сховища перевіряє відкладену обробку відповіді GET та збереження підтвердженої оцінки. Фактичний FPS і ривок на конкретному Android ще потребують профілювання на пристрої.


### Наліпки з ілюстраціями — 0.3.9+18

Ручний перегляд: кутовий жест знімає текстову наліпку й відкриває локальну картинку. Наступні жести показують решту картинок; протилежний до останнього жест повертає попередній шар, а після останнього зображення відкривається текст. Наліпка слідує за пальцем, має діагональний згин і тінь; скасування повертає її на місце. Центр тексту залишається доступним для прокручування довгих прикладів. Натискання перемикає слово/переклад. На картинці є лічильник і кнопка повернення до слова. Автоматичного показу в цій версії немає.

Приватна збірка використовує локальні ілюстрації для 1403 словникових записів; не всі слова мають картинку. Приватні каталоги й зображення не додаються в Git. Перед збіркою виконайте `node android/tool/prepare_sticker_assets.mjs`: за наявності локального assets/lexicon/index.json скрипт формує індекс доступних файлів; без приватних даних створює порожній каталог для збірки без ілюстрацій. Картинки беруться з assets/word-images/images/*.webp; мережевих пошуків під час свайпу немає.

Перевірено всі чотири кути, зворотний рух, кілька картинок, повний цикл, скасування й перегляд справжньої локальної картинки в сесії. Фізичний Android та схожість ефекту з очікуванням користувача ще потребують перевірки.


### Непрозорі наліпки та округлі картинки — 0.3.10+19

Зображення заокруглюються за власними фактичними межами всередині картки, включно з відступами при fit: contain. Текстові наліпки з картинками мають непрозорий фон; під час відклеювання верхній шар закриває нижній до лінії згину. Колірна підсвітка за родом зберігається. Ключі шарів утримують верхній віджет при додаванні нижньої картинки. Піксельний тест перевіряє приховування картинки в не відклеєній області, видимість у відклеєній області та заокруглення самої картинки.


### Фіксований екран, розмір із 0.3.1 і вибір шрифту — 0.3.11+20

Екран карток більше не містить зовнішнього ListView і не прокручується. Картка має базову висоту 280 px (216 px вмісту + 32 px відступів із кожного боку) з 0.3.1; варіант 320 px скасовано. Довгий вміст прокручується лише всередині картки. На малих екранах ущільнено керування, а оцінки розкладено у два ряди по три. FittedBox зі scaleDown — резерв для надто низької доступної області, щоб елементи не обрізались; у перевірених портретних 320×568 і 390×844 фактична висота залишається 280 px.

Шрифт вибирається в персоналізації або налаштуваннях сесії: Roboto із 0.3.1 чи поточний Outfit. Вибір локально зберігається разом з іншими налаштуваннями вигляду; в налаштуваннях сесії застосовується після збереження. Оновлюються і тема, і явні стилі слова/прикладів/селекторів. Типово залишається Outfit.

Нові тести перевіряють відсутність зовнішньої прокрутки, сталі 280 px, доступність шести оцінок без перекриття навігацією, збереження/скасування обох шрифтів та зміну шрифту тексту картки.


### Контрольна версія 0.3.11

Стабільний знімок позначено тегом v0.3.11. Подальші зміни ведуться в experimental. Для чистого checkout перед flutter pub get виконайте node android/tool/prepare_sticker_assets.mjs.
